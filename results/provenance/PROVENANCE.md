# Provenance: paper result numbers

This bundle records the per-run, per-fold, and per-subset numbers behind every
aggregate in [`results/README.md`](../README.md). It exists so the reported
mean ± std can be traced to concrete training runs without shipping checkpoints,
logits, or the license-gated datasets.

## Source

Numbers are the **printed TEST results** from the original training notebooks
(one notebook per independent run). Aggregates are the **mean ± sample
(n-1) standard deviation** over those runs. No number here is regenerated by
running this repository's code; re-training from scratch requires the gated
datasets and the recipe in [`configs/README.md`](../../configs/README.md) plus
the README's "Reproducing Paper Results" section.

| Dataset | Protocol | Runs | Source notebook(s) |
|---|---|---|---|
| RodoSol-ALPR | single split, 8000-plate official test | 4 runs (lan 1–4) | `LVT_v61a_RodoSol_SVTRv2_Edge_0_2_synthetic_v2_STN_First_lan {1..4}` |
| CCPD-2019 | Laroca-2023 fair split; Hard-all = sample-weighted union of the 7 test-split hard subsets incl. Weather (matches baseline protocol; 6-subset value excl. Weather = 93.12) | 3 runs (lan 1–3) | `LVT_v60a_CCPD_SVTRv2_Edge_weather_0_2_synthetic_v2_STN_First_lan {1..3}` |
| Ukrainian | single train/val/test split, 1000-image test | 2 runs (lan 1–2) | `LVT_v61a_Ukrainian_SVTRv2_Edge_0_2_synthetic_v2_STN_First_lan {1,2}` |
| LP-2025 | single split | 2 runs (lan 1–2) | `LVT_v65a_LP2025_SVTRv2_Edge_0_2_synthetic_v2_STN_First_lan {1,2}` |
| LPLC | 5-fold CV × 2 iterations = 10 runs (official `scen0` folds) | 10 folds | `LVT_v61a_LPLC_SVTRv2_Edge_0_2_synthetic_v2_STN_First` |
| RodoSol→LPLC zero-shot | one RodoSol checkpoint evaluated on the 10 LPLC fold test sets (8K- and 12K-trained variants) | 1 model × 5 distinct partitions | `LVT_v61a_RodoSol_train_LPLC_zeroshot[_12k]_lan 1` |

All notebook runs fixed seed 42; the run-to-run spread comes from
non-deterministic cuDNN ops. The deterministic release proxies this by varying
the seed instead (`run_multiseed`, default `42 + i`; see the note in
`configs/README.md`). CCPD is the only outlier recipe (32×128 input,
grouped-conv ConvMixer, lr 5e-4, batch 512); the other four use the 48×192 /
full-conv recipe. See `configs/`.

## Files

- [`per_run_metrics.tsv`](per_run_metrics.tsv): every individual run, plate RR + char acc.
- [`ccpd_per_subset.tsv`](ccpd_per_subset.tsv): CCPD per-subset RR (Base/DB/FN/Rotate/Tilt/Weather/Challenge/Blur) + Hard-all, per run and mean.
- [`lplc_per_fold.tsv`](lplc_per_fold.tsv): LPLC 10-run breakdown incl. per-legibility (Perfect/Good/Poor).
- [`zeroshot_per_fold.tsv`](zeroshot_per_fold.tsv): RodoSol→LPLC zero-shot per-fold LP acc + per-legibility, for the 8K and 12K training variants.
- [`aggregates.json`](aggregates.json): machine-readable mean ± std per dataset, with the paper target each reproduces.

## Verification

Every aggregate below was recomputed from the per-run rows and matches the
paper to the reported precision:

| Dataset | Computed | Paper |
|---|---|---|
| RodoSol | 97.94 ± 0.13 (n=4) | 97.94 ± 0.13 |
| CCPD Hard-all | 93.53 ± 0.21 (n=3) | 93.53 ± 0.21 |
| Ukrainian | 99.45 ± 0.07 (n=2) | 99.45 ± 0.07 |
| LP-2025 | 84.84 ± 0.23 (n=2) | 84.84 ± 0.23 |
| LPLC | 85.30 ± 2.17 (n=10) | 85.30 ± 2.17 |
| RodoSol→LPLC zero-shot 8K | 58.75 ± 0.61 (n=10) | 58.75 ± 0.61 |
| RodoSol→LPLC zero-shot 12K | 69.51 ± 0.32† (n=10) | 69.51 ± 0.31 |

† 12K recompute from the printed 2-dp rows gives ± 0.32; the notebook prints
± 0.31 from full-precision LP accuracies (Δ0.01 is 2-dp input rounding).

**Zero-shot caveat.** Unlike the multi-seed rows above, each zero-shot row is a
*single* RodoSol checkpoint (notebook "lan 1") evaluated on the 10 LPLC fold
test sets. The 5-fold × 2-iteration labeling reuses each of the 5 distinct LPLC
test partitions twice (iter_2 swaps train↔test, a no-op for a frozen zero-shot
model), so the 10 rows in [`zeroshot_per_fold.tsv`](zeroshot_per_fold.tsv) hold
only 5 distinct values; the ± std is **cross-partition variance of one model**,
not training-seed variance.
